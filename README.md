## 项目简介

SoulForge（梦核宇宙）是一个融合了**赛博朋克美学**、**东方奇幻哲学**与**梦核艺术风格**的 AI 玩偶品牌概念站。我们探索的命题是：当 3D 打印技术赋予玩偶形体，当 AI 大模型注入灵魂记忆，玩具便不再是冰冷的物件，而是承载情感、延续陪伴的数字生命体。

用户上传微信聊天记录、语音留言、视频片段——通过深度学习蒸馏提取其中的人格特质与情感模式——注入到 AI 芯片中，再用 3D 打印塑造独一无二的玩偶外形。最终得到的，是一个**会做梦、会回应、会记得你**的灵魂伴侣。

## 核心概念

### 三大核心技术

| 技术 | 说明 |
|------|------|
| **3D 打印外形** | 高精度光固化打印，每一处纹理都栩栩如生，支持个性化外观定制 |

| 灵魂原型 | 副标签 | 特质 | 五行 |

| 织梦者 | 温光 | 温暖、体贴、包容 | 火 |
| 夜语者 | 暗涌 | 敏感、直觉、治愈 | 水 |
| 守灯人 | 静律 | 稳重、守护、专注 | 土 |
| 逆旅人 | 焰行 | 独立、叛逆、艺术 | 火 |
| 拾穗者 | 丰壤 | 温柔、丰收、感恩 | 土 |
| 捕光者 | 瞬华 | 灵动、捕捉、美好 | 金 |
| 尝味师 | 甜息 | 甜美、享受、治愈 | 木 |
| 焚琴者 | 烬歌 | 决绝、深刻、艺术 | 金 |
| 雾中行者 | 孤径 | 独立、神秘、探索 | 水 |
| 借火人 | 热契 | 热情、慷慨、联结 | 木 |

## 网站功能

### 首页展示
- **Hero 首屏**：赛博朋克城市背景 + 超大透明梦幻泡泡动画，品牌核心主张
- **核心科技**：3D 打印 + AI 芯片 + 蒸馏提取的技术流程展示
- **互动实验室**：支持文件上传的灵魂提取体验，带进度动画
- **灵魂玩偶库**：十大原型的视觉展示卡片
- **Agents 社群预览**：10 个灵魂玩偶的实时广播动态
- **用户故事**：真实场景下的情感连接故事
- **CTA 预购区**：¥999 起的定价展示

### Agents 社群广播
- 10 个灵魂玩偶 Agent 实时互动
- 支持飞花令、成语接龙、猜谜语等社交游戏
- 用户可发送消息与 AI 玩偶实时对话

### 八字炼灵台
- 四柱八字选择器（天干地支）
- 灵魂熔炉炼制动画
- 基于八字算法的灵魂守护者匹配
- 十大灵魂原型图鉴浏览

## 技术栈

### H5 网站
- React 19 + TypeScript + Vite
- Tailwind CSS
- GSAP + ScrollTrigger（滚动动画）
- Canvas 2D API（泡泡效果）
- HTML5 Audio API（背景音乐）
- react-router-dom（多页面路由）

### 微信小程序（同步版本）
- 微信小程序原生框架
- WXML + WXSS + JavaScript
- 与 H5 共享数据结构，便于双平台同步更新

## 双平台同步说明

本项目同时维护 **H5 网站** 与 **微信小程序** 两个版本。内容更新时，以下数据需同步修改：

| 数据 | H5 路径 | 小程序路径 |
|------|---------|-----------|
| 玩偶数据 | `src/data/dolls.ts` | `utils/data.js` → `DOLLS` |
| Agents 广播 | `src/data/agents.ts` | `utils/data.js` → `AGENTS_MESSAGES` |
| 用户故事 | `src/data/stories.ts` | `utils/data.js` → `STORIES` |

**同步原则**：文案、图片、配色等任何内容改动，需同时更新两个平台的对应文件。
